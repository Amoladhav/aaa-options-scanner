# Historical source reference

Only the incoming momentum ranker, its example configuration, and its ranker tests
are accepted in this initial snapshot. They were scanned and statically reviewed;
they are not runnable application code and must not be imported or collected.
Their imports reference dependencies intentionally absent from this snapshot.

Source: user-supplied `INBOX/options-trading-scanner`. Original filenames and
authorship comments are preserved. No standalone license or author grant was
found in the inventory; redistribution rights remain unresolved. This local
reference is not approval to publish or redistribute the incoming source.

See [manifest](../docs/intake-manifest.json) for every accepted and excluded path,
and [findings](../docs/intake-findings.json) for value-suppressing disposition.
The raw original remains outside this repository. The active implementation will
live only in `src/`; subsequent commits document its differences from this record.
